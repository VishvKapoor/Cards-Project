# 🎴 React Props Card App

A simple React.js project demonstrating the concept of **props** by creating reusable Card components. Each card displays dynamic content passed from a parent component.

## 🚀 Features

- 🧩 Reusable Card components using props
- 🔄 Dynamic data rendering
- 🎨 Clean and simple UI design
- ⚡ Fast and lightweight frontend app
- 💻 Built purely with React (no backend)

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
